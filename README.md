# B Bharadwaj — Portfolio

Personal portfolio website built with [Magic Portfolio](https://once-ui.com/products/magic-portfolio) by Once UI.

## Stack

- **Framework** — Next.js 15 (App Router)
- **Styling** — Once UI design system
- **Content** — MDX for project case studies
- **Deployment** — Vercel

## Pages

- **Home** — Full showcase with skills, experience, featured projects and contact
- **About** — Full CV with experience, technical skills, education and certifications
- **Work** — Filterable project showcase with case study pages

## Projects

- RAG Analytics Platform
- Claim Reimbursement System
- Alzheimer's & Parkinson's Protein Detection
- Self-Evolving Neural Network (SENN)
- Medical Report Simplifier

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
