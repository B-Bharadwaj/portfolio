## Overview

A Neural Architecture Search (NAS) framework that uses evolutionary algorithms to automatically discover efficient CNN architectures, inspired by biological evolution. Live evolution tracking via a Streamlit dashboard.

## Key Features

- **Architecture DNA**: Each CNN architecture is encoded as a mutable "DNA" string — layers, filters, activations — that can be mutated and crossed over like biological genes.
- **NSGA-II Pareto Selection**: Multi-objective optimisation balancing accuracy and model efficiency simultaneously using the Non-dominated Sorting Genetic Algorithm II.
- **Structured L1-norm Pruning**: Post-evolution pruning to reduce model size while preserving accuracy.
- **Streamlit Dashboard**: Real-time visualisation of the evolutionary process — fitness curves, architecture mutations, and Pareto frontiers.
- **CIFAR-10 Benchmark**: Validated on the standard image classification benchmark.

## Technologies Used

- **PyTorch** — Model construction and training
- **NSGA-II** — Multi-objective evolutionary optimisation
- **Streamlit** — Live evolution tracking dashboard
- **NumPy** — Genetic operators (mutation, crossover, selection)

## Challenges & Learnings

Balancing exploration (diverse mutations) vs exploitation (refining good architectures) was the core challenge. NSGA-II's Pareto selection naturally handled the accuracy-efficiency tradeoff without manual weighting.
