## Overview

Built an evolutionary Neural Architecture Search framework that automatically discovers efficient CNN architectures using genetic algorithms and multi-objective optimisation, with live tracking via a Streamlit dashboard.

## What I Did

- Built an evolutionary NAS framework with mutation-driven Architecture DNA encoding layer types, filter sizes, and activations as mutable gene sequences.
- Applied NSGA-II Pareto selection to simultaneously optimise for accuracy and model efficiency, auto-discovering CNN architectures on CIFAR-10 without manual design.
- Implemented structured L1-norm pruning post-evolution to reduce model size while preserving accuracy.
- Built a Streamlit dashboard for live tracking of fitness curves, architecture mutations, and Pareto frontiers across generations.

## Technologies Used

- **PyTorch** — Model construction and training
- **NSGA-II** — Multi-objective evolutionary optimisation
- **Streamlit** — Live evolution tracking dashboard
- **NumPy** — Genetic operators (mutation, crossover, selection)

## Challenges & Learnings

Balancing exploration of diverse mutations versus exploitation of good architectures was the core challenge. NSGA-II Pareto selection naturally handled the accuracy-efficiency tradeoff without manual weighting — which was the key insight that made the framework work well.
