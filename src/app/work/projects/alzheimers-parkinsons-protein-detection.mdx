## Overview

A deep learning system for classifying Alzheimer's, Parkinson's, and normal protein sequences using TAPE embeddings and multiple neural architectures. Instead of clinical or imaging data, the model learns sequence-level patterns associated with disease-linked misfolding — making predictions interpretable through attention heatmaps.

## What I Did

- Trained and benchmarked four architectures on TAPE protein embeddings — MLP baseline, BiLSTM + Risk, BiLSTM + Luong Attention, Transformer, and CNN-BiLSTM — achieving up to 82% accuracy on 3-class classification.
- Added an auxiliary misfolding risk regression head alongside classification, predicting protein stability scores and providing richer biological insight beyond class labels.
- Generated attention heatmaps for misclassified sequences, visualising which amino acid positions the model focused on — making predictions explainable to domain experts.
- Built a full preprocessing pipeline: `.pdb` sequence extraction → TAPE embedding generation → data augmentation with sliding windows → train/val/test splits.
- Evaluated models across Accuracy, Precision, Recall, F1, and Misfolding Risk MSE — with embedding projections (t-SNE, PCA) for visual analysis.

## Results

| Model | Accuracy | Misfolding Risk MSE |
|---|---|---|
| BiLSTM + Attention | 0.70+ | 0.08–0.11 |
| BiLSTM + Risk | 0.65–0.83 | 0.09–0.12 |
| Transformer + Risk | 0.67–0.82 | 0.10–0.14 |
| CNN-BiLSTM + Risk | ~0.65 | ~0.11 |

## Challenges & Learnings

Protein sequence data required domain-specific preprocessing — extracting sequences from `.pdb` files and generating TAPE embeddings before any modelling could begin. The multi-task setup combining classification and regression improved generalisation. Attention heatmaps were critical for making results meaningful to biologists — accuracy alone was not sufficient justification for a medical AI system.
