## Overview

Built a deep learning system for classifying Alzheimer's and Parkinson's disease biomarkers from protein sequences, using state-of-the-art sequence modelling architectures on TAPE protein embeddings.

## What I Did

- Trained and benchmarked BiLSTM + Luong Attention, CNN-BiLSTM, and Transformer classifiers on TAPE protein embeddings for 3-class neurodegenerative disease detection, achieving 82% accuracy.
- Added an auxiliary misfolding risk regression head alongside the classification task, improving model generalisation across protein sequence variations.
- Generated attention heatmaps for sequence-level interpretability on Homo sapiens .pdb data, making predictions explainable to domain experts.
- Evaluated all three architectures systematically to identify the best-performing model for each classification scenario.

## Technologies Used

- **PyTorch** — Model training and architecture implementation
- **TAPE** — Pre-trained protein sequence embeddings
- **BiLSTM + Attention** — Primary sequence model
- **Transformer** — Comparative architecture
- **Matplotlib / Seaborn** — Attention heatmap visualisation

## Challenges & Learnings

Working with biological sequence data required understanding domain-specific preprocessing. The multi-task setup combining classification and regression improved generalisation. Attention heatmaps made results explainable to domain experts — a critical requirement for medical AI.
