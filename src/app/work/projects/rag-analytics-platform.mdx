## Overview

Built a production-grade AI BI platform that enables natural language querying over both unstructured PDFs and structured databases through a single unified interface.

## What I Did

- Built a Multi-PDF RAG system with hybrid FAISS + BM25 retrieval, improving retrieval accuracy over single-method approaches.
- Designed a PostgreSQL Text-to-SQL pipeline exposed via 24 FastAPI endpoints with full SQL logging for auditability.
- Integrated built-in LLM evaluation metrics — faithfulness, relevance, and completeness — running on every query response.
- Developed a React + Plotly frontend with role-aware routing, allowing non-technical stakeholders to query both data sources without writing code.

## Technologies Used

- **FastAPI** — API layer with async endpoints
- **FAISS + BM25** — Hybrid vector + keyword retrieval
- **PostgreSQL** — Structured data source with Text-to-SQL
- **React + Plotly** — Frontend with interactive visualisations
- **LangChain / LLM** — Retrieval orchestration and evaluation

## Challenges & Learnings

The core challenge was making retrieval work reliably across both structured and unstructured sources in a single query. Hybrid FAISS + BM25 retrieval significantly outperformed either approach alone. Building the LLM evaluation layer taught me a lot about measuring AI output quality in production.
