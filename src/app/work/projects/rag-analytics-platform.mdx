## Overview

A production-grade AI BI platform for querying both unstructured PDFs and structured databases through a single natural language interface — with built-in evaluation, SQL auditability, and chart generation.

## What I Did

- Implemented hybrid FAISS HNSW + BM25 retrieval with cross-encoder reranking and 3-variation LLM query expansion, improving retrieval precision and recall over single-method approaches.
- Built a PostgreSQL Text-to-SQL pipeline with full query logging — every answer traceable to the exact SQL that produced it.
- Integrated Groq Vision (llama-4-scout) for per-figure captioning from PDF crops, stored as searchable chunks.
- Built an on-demand LLM evaluation pipeline (llama-3.3-70b) scoring Faithfulness, Answer Relevancy, and Context Recall — surfacing the high faithfulness + low context recall failure pattern.
- Developed SQL-driven analytics with anomaly detection, executive summaries, and a chart generation pipeline supporting bar, line, pie, histogram, and scatter charts.
- Built a React + Plotly frontend with role-aware routing, multi-paper comparison, and inline figure rendering.

## Technologies Used

- **FastAPI** — 24 async endpoints
- **FAISS HNSW + BM25** — Hybrid retrieval with cross-encoder reranking
- **PostgreSQL** — Text-to-SQL pipeline
- **Groq Vision / LLM Judge** — Figure captioning and evaluation
- **React + Plotly + Chart.js** — Frontend and visualisations
- **PyMuPDF** — PDF parsing and figure extraction

## Challenges & Learnings

Hybrid FAISS + BM25 with cross-encoder reranking solved precision, but query expansion was critical for short or ambiguous inputs where neither method performed well alone.

On the data side, reliable Text-to-SQL required the LLM to read the full schema before generating queries, with a NOT_SQL fallback preventing silent failures. Keeping all analytics SQL-driven with no Pandas statistics sent to the LLM noticeably improved answer accuracy.

The most non-obvious finding — high faithfulness combined with low context recall — where the model gives confident but incomplete answers. Building evaluation to surface this explicitly was the most valuable addition.
