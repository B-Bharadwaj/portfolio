## Overview

Built a PDF-to-plain-English pipeline that simplifies medical reports for patients while maintaining complete safety and accuracy of critical medical information.

## What I Did

- Built a PDF-to-plain-English pipeline using Gemini 2.5 Flash, reducing Flesch-Kincaid readability grade from 14–16 to 7–9 across test documents.
- Designed a 3-layer safety evaluation system covering negation detection, critical term retention, and semantic similarity scoring — achieving 100% negation safety across all test cases.
- Implemented an auto-rewrite module that detects unsafe simplifications and corrects them before output, eliminating the need for manual safety review.
- Validated output quality across multiple document types including diagnostic reports, discharge summaries, and prescription notes.

## Technologies Used

- **Gemini 2.5 Flash** — LLM for medical text simplification
- **Python** — Pipeline orchestration
- **NLP libraries** — Negation detection and semantic similarity
- **PDF parsing** — Extracting structured text from medical documents

## Challenges & Learnings

Medical text simplification is a high-stakes NLP problem. The key insight was that readability alone is not enough — you need explicit safety constraints. Building the negation detection and auto-rewrite loop was the most technically interesting part of the project.
