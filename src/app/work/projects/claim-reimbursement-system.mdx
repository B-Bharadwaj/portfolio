## Overview

Built a full-stack claim reimbursement platform with an automated claim lifecycle, OCR-based receipt processing, and role-specific dashboards for Employee, Manager, and Finance users.

## What I Did

- Built an end-to-end reimbursement platform in Django + PostgreSQL with a 5-stage automated claim lifecycle — Draft, Submitted, Manager Review, Finance Review, and Settled.
- Integrated a FastAPI + Tesseract OCR microservice that extracts vendor, date, and amount from unstructured receipts into structured JSON, with user-authoritative override for corrections.
- Implemented JWT authentication and role-based access control across 3 user roles, streamlining approval workflows and reducing unauthorised access risk.
- Designed and deployed production-ready REST APIs with modular architecture for clean separation between claim processing, document handling, and user management.

## Technologies Used

- **Django + DRF** — Core backend and REST API
- **React** — Frontend with role-specific dashboards
- **FastAPI + Tesseract** — OCR microservice for receipt parsing
- **PostgreSQL** — Database with relational claim and user models
- **JWT** — Authentication and session management

## Challenges & Learnings

Making OCR reliable across different receipt formats was the hardest part. The solution was building a confidence-scoring layer and always giving users the ability to correct extracted values — keeping humans in the loop for accuracy.
