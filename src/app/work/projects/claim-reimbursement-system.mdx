## Overview

Built during my internship at Innoventes — a full-stack claim reimbursement platform with an automated claim lifecycle, OCR-based receipt processing, and role-specific dashboards for Employee, Manager, and Finance users. Designed for production-grade enterprise environments with a clean service-oriented architecture.

## What I Did

- Built a 5-stage automated claim lifecycle — DRAFT → SUBMITTED → MANAGER_APPROVED / REJECTED → FINANCE_APPROVED → PAID — with enforced state transitions and full audit trail.
- Implemented role-based access control across 3 user roles (Employee, Manager, Finance) with JWT authentication and automatic token refresh for seamless sessions.
- Built a dedicated FastAPI + Tesseract OCR microservice that extracts vendor name, date, amount, confidence score, and raw text from receipt images and PDFs — auto-filling claim forms with user-authoritative override.
- Designed RESTful APIs in Django REST Framework covering authentication, claims lifecycle, approvals, payments, and receipt uploads — with clear separation between backend, frontend, and OCR service.
- Built role-specific React dashboards — Employees track claim status end-to-end, Managers approve or reject with comments, Finance performs final validation and marks claims as paid.

## Technologies Used

- **Django + DRF** — Core backend, REST APIs, and workflow logic
- **React** — Role-based dashboards with protected routing
- **FastAPI + Tesseract** — Independent OCR microservice
- **PostgreSQL** — Primary data store with relational claim and user models
- **JWT** — Authentication and session management

## Challenges & Learnings

Making OCR reliable across varied receipt formats was the hardest technical problem. The solution was treating OCR as an assistive feature — never a blocking dependency — with a confidence score returned alongside extractions and users always able to override values. Designing the claim lifecycle as strict state transitions prevented invalid workflow jumps and made the system audit-ready from the start.
